# Opportunity Intelligence Engine (OIE)

Opportunity Intelligence Engine (OIE) is a modular pipeline for discovering commercial opportunities from job postings. It provides a FastAPI API to create runs, execute the complete pipeline or individual stages, inspect artifacts, monitor execution, schedule future executions, and integrate with external systems.

The project is designed around independent pipeline stages, checkpointing, resumability, observability, and deterministic execution.




Returns an overview of every pipeline stage, indicating which artifacts are available (checkpoint, metrics, output), together with execution status and artifact paths.

## Run Scheduling

```
POST /runs/{run_id}/schedule
PUT /runs/{run_id}/schedule
GET /runs/{run_id}/schedule
GET /runs/{run_id}/schedule/status
```

Each run may have an associated execution schedule.

Supported fields:

- frequency: `daily`, `weekly`, `monthly`
- duration: `permanent`, `1 week`, `2 weeks`, `1 month`, etc.
- scheduled_times: one or more `HH:MM` values
- scheduled_days: optional weekdays
- enabled: enables or disables the schedule

Example:

```json
{
    "frequency": "weekly",
    "duration": "permanent",
    "scheduled_times": [
        "09:00",
        "15:00"
    ],
    "scheduled_days": [
        "monday",
        "wednesday"
    ],
    "enabled": true
}
```

# Typical Execution Flow

## 1. Create a run

```bash
curl -X POST http://127.0.0.1:8000/runs \
    -H "Content-Type: application/json" \
    -d '{
        "config":{
            "runs":{
                "path":"runs"
            }
        },
        "flags":{
            "dry_run":true
        }
    }'
```

---

## 2. (Optional) Configure a schedule

```bash
curl -X POST \
http://127.0.0.1:8000/runs/{run_id}/schedule \
-H "Content-Type: application/json" \
-d '{
    "frequency":"weekly",
    "duration":"permanent",
    "scheduled_times":["09:00"],
    "scheduled_days":["monday"],
    "enabled":true
}'
```

---

## 3. Execute the entire pipeline

```bash
curl -X POST \
http://127.0.0.1:8000/runs/{run_id}/execute
```

---

## 4. Execute an individual stage

```bash
curl -X POST \
http://127.0.0.1:8000/runs/{run_id}/stages/company_gate/execute
```
